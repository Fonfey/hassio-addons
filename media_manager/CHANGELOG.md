# Changelog

## 1.1.0

- The app is now in the store repository [Fonfey/hassio-addons](https://github.com/Fonfey/hassio-addons) and is delivered as a ready-made image.
- New setting **Folder**: choose which folder the app shows. /media by default; a folder inside it or a folder in /share also works.
- De app staat nu in de store-repository [Fonfey/hassio-addons](https://github.com/Fonfey/hassio-addons) en wordt als kant-en-klaar image geleverd.
- Nieuwe instelling **Map**: kies welke map de app toont. Standaard /media; een map daarin of een map in /share kan ook.

## 1.0.1

- Fixed: deleting, renaming, moving, making a folder and uploading did nothing (or saved an empty file) when used through Home Assistant.
- Opgelost: verwijderen, hernoemen, verplaatsen, een map maken en uploaden deden niets (of bewaarden een leeg bestand) als je de app via Home Assistant gebruikte.

## 1.0.0

- First version. Shows the media folder with thumbnails, full file names and the date taken, grouped by month or year, with filters for year and kind.
- Upload by dragging or with the Upload button, also for large videos through Nabu Casa. Rename, move, download (several files as one zip) and delete, with a trash that keeps files for 30 days.
- Copy the media-source address or the file path to use a file in Home Assistant.
- Eerste versie. Toont de mediamap met miniaturen, volledige bestandsnamen en de opnamedatum, gegroepeerd per maand of jaar, met filters voor jaar en soort.
- Uploaden door te slepen of met de knop Uploaden, ook voor grote video's via Nabu Casa. Hernoemen, verplaatsen, downloaden (meerdere bestanden als één zip) en verwijderen, met een prullenbak die bestanden 30 dagen bewaart.
- Het media-source-adres of het bestandspad kopiëren om een bestand in Home Assistant te gebruiken.
