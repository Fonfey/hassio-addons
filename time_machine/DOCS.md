# Time Machine

[English](#english) · [Nederlands](#nederlands)

## English

Home Assistant does not keep earlier versions of what you build in the editor. If you accidentally save something wrong or delete an automation, the old version is gone, unless you restore a full backup. Time Machine keeps a version on every change, so you can restore one item without touching the rest.

The app follows the language of your Home Assistant: Dutch if Home Assistant is set to Dutch, English otherwise.

### What is kept

| Item | Restore |
| --- | --- |
| Automations | Yes, also as a copy and also after deleting |
| Scripts | Yes, also as a copy and also after deleting |
| Scenes | Yes, also as a copy and also after deleting |
| Dashboards | Yes, as a whole. After deleting: first create the dashboard again with the same URL |
| Helpers (toggles, numbers, dropdowns, text, date and time, buttons, counters, timers, schedules) | Yes, also as a copy and also after deleting |

Dashboards are listed under the name from your sidebar. Built-in dashboards such as Home, Lights, Security, Climate and Energy are generated by Home Assistant itself; there is nothing to keep. Dashboards in a YAML file, or with nothing saved yet, are not kept either. The Dashboards filter shows which ones.

Only what you create in Home Assistant itself is kept. Items from YAML files or packages are managed in those files, so Time Machine skips them.

### How it works

- Choose an item on the left. You see all kept versions, with when and what changed.
- Choose a version to see the difference with now: red is what was there, green is what is there now.
- **Restore this version** restores the item, after confirmation. Your current version is kept, so you can always go back.
- **Restore as copy** creates a new item with the old content, next to the original. A copy of an automation is turned off right away, so it does not run twice; turn it on in Home Assistant if you want to use it.
- **Delete** removes an automation, script, scene or helper from Home Assistant, after confirmation. The versions stay in Time Machine, so you can always restore it.
- **Delete permanently** also erases the kept versions. This is possible for a copy (which is then also removed from Home Assistant) and for an item that has already been deleted. This cannot be undone.
- **Discard this version** removes one version you no longer need, for example an intermediate step with a mistake. The other versions and the item itself stay as they are. You cannot discard the current version.

Time Machine notices a change as soon as Home Assistant reports it, and also checks by itself every few minutes. The first version of each item is the version at the moment you install the app.

If you delete an automation in the **Maintenance** app, the **Restore in Time Machine** button takes you straight to that automation here.

### Settings

- **Keep versions (days)**: 30 by default.
- **Always keep per item**: the last 5 by default, even when they are older.
- **Check every (minutes)**: 5 by default.
- **Allowed administrators (optional)**: only administrators see the sidebar item; enter usernames if not every administrator may see Time Machine.

The versions are stored in the app's storage, so they are included in Home Assistant backups.

### Local

The app runs completely locally: it only talks to your own Home Assistant and loads nothing from the internet, not even fonts.

## Nederlands

De app volgt de taal van je Home Assistant: Nederlands als Home Assistant Nederlands is, anders Engels. In de store heet de app Time Machine.

Home Assistant bewaart geen eerdere versies van wat je in de editor maakt. Sla je per ongeluk iets verkeerds op of verwijder je een automation, dan is de oude versie weg, tenzij je een hele back-up terugzet. De Tijdmachine bewaart bij elke wijziging een versie, zodat je één onderdeel kunt terugzetten zonder de rest aan te raken.

### Wat wordt bewaard

| Onderdeel | Terugzetten |
| --- | --- |
| Automations | Ja, ook als kopie en ook na verwijderen |
| Scripts | Ja, ook als kopie en ook na verwijderen |
| Scènes | Ja, ook als kopie en ook na verwijderen |
| Dashboards | Ja, in zijn geheel. Na verwijderen: maak het dashboard eerst opnieuw aan met dezelfde URL |
| Helpers (schakelaars, getallen, keuzelijsten, tekst, datum en tijd, knoppen, tellers, timers, schema's) | Ja, ook als kopie en ook na verwijderen |

Dashboards staan in de Tijdmachine onder de naam uit je zijbalk. Ingebouwde dashboards zoals Thuis, Verlichting, Beveiliging, Klimaat en Energie bouwt Home Assistant zelf op; daar is niets van te bewaren. Dashboards in een YAML-bestand, of waar nog niets in is opgeslagen, worden ook niet bewaard. Bij het filter Dashboards zie je welke dat zijn.

Alleen wat je in Home Assistant zelf maakt, wordt bewaard. Onderdelen uit YAML-bestanden of pakketten beheer je in die bestanden, dus die slaat de Tijdmachine over.

### Zo werkt het

- Kies links een onderdeel. Je ziet alle bewaarde versies, met wanneer en wat er veranderde.
- Kies een versie en je ziet het verschil met nu: rood is wat er was, groen wat er nu staat.
- **Deze versie terugzetten** zet het onderdeel terug, na bevestiging. Je huidige versie blijft bewaard, dus je kunt altijd terug.
- **Als kopie terugzetten** maakt een nieuw onderdeel met de oude inhoud, naast het origineel. Een kopie van een automation staat meteen uit, zodat hij niet dubbel draait; zet hem aan in Home Assistant als je hem wilt gebruiken.
- **Verwijderen** haalt een automation, script, scène of helper uit Home Assistant, na bevestiging. De versies blijven in de Tijdmachine, dus je kunt hem altijd terugzetten.
- **Definitief verwijderen** wist ook de bewaarde versies. Dat kan bij een kopie (die wordt dan meteen ook uit Home Assistant gehaald) en bij een onderdeel dat al verwijderd is. Dit kan niet ongedaan worden.

De Tijdmachine merkt een wijziging meteen als Home Assistant die meldt, en controleert daarnaast zelf elke paar minuten. De eerste versie van elk onderdeel is de versie op het moment dat je de app installeert.

Heb je een versie niet meer nodig, bijvoorbeeld een tussenstap met een fout, kies hem dan in de lijst en druk op **Deze versie weggooien**. Alleen die versie verdwijnt; de andere versies en het onderdeel zelf blijven zoals ze zijn. De huidige versie kun je niet weggooien.

Verwijder je een automation in de app **Maintenance** (Onderhoud), dan brengt de knop **Terugzetten in de Tijdmachine** je hier meteen naar die automation.

### Instellingen

- **Versies bewaren (dagen)**: standaard 30.
- **Altijd bewaren per onderdeel**: standaard de laatste 5, ook als ze ouder zijn.
- **Controleren elke (minuten)**: standaard 5.
- **Toegestane beheerders (optioneel)**: alleen beheerders zien de knop in de zijbalk; vul gebruikersnamen in als niet elke beheerder de Tijdmachine mag zien.

De versies staan in de opslag van de app en gaan dus mee in de back-ups van Home Assistant.

### Lokaal

De app draait helemaal lokaal: hij praat alleen met je eigen Home Assistant en laadt niets van internet, ook geen lettertypen.
